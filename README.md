# E-Commerce Sales Analysis

## Project Overview
This project focuses on analyzing e-commerce sales data to understand business performance, product sales, customer purchasing patterns, and payment preferences.

The project follows an end-to-end data analytics workflow, starting from raw data cleaning using Python to SQL-based analysis and interactive dashboard development using Power BI.

## Tools & Technologies Used
- **Python:** Data cleaning and preprocessing.
- **Pandas & NumPy:** Data manipulation and transformation.
- **Excel:** Dataset inspection.
- **MySQL:** Data storage and SQL analysis.
- **Power BI:** Interactive dashboard and data visualization.
- **VS Code:** Python development environment.

## Project Workflow

1. **Data Collection:** Imported the raw e-commerce dataset using Excel.
2. **Data Cleaning:** Used Python and Pandas to handle duplicates, missing values, inconsistent text, and invalid records.
3. **Data Transformation:** Converted date and numeric columns into appropriate formats.
4. **Feature Engineering:** Created new columns such as Sales, Net Amount, Profit, Month, Year, and Weekday.
5. **SQL Analysis:** Imported the cleaned dataset into MySQL and performed queries to analyze sales, products, cities, and payment modes.
6. **Dashboard Development:** Connected the analyzed data to Power BI and created an interactive dashboard.

## Dashboard Highlights

The Power BI dashboard includes:

- Total Sales
- Total Orders
- Total Profit
- Average Order Value
- Monthly Sales Trend
- Sales by Category
- Sales by Product
- Sales by City
- Payment Mode Distribution
- Order Status Analysis
- Profit by Category

## Key Insights
- Analyzed overall sales and profit performance.
- Compared sales across different product categories.
- Identified products contributing to higher sales.
- Examined monthly sales trends.
- Analyzed payment mode distribution.
- Explored order status and city-wise sales performance.

## Project Outcome

This project demonstrates practical knowledge of data cleaning, data preprocessing, SQL querying, data analysis, and dashboard development. It showcases how raw e-commerce data can be transformed into meaningful business insights using data analytics tools.
